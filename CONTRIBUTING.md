# Contributing to WLVArch.AI

The full, step-by-step guide is on the site's **Contribute** page, and its source is `contribute.md` in this repository.

The short version:

1. Copy the relevant template from `_templates/`.
2. Save it in the right folder (`_posts`, `_workflows` or `_showcase`) with a lower-case, hyphenated file name. Session posts must start with the date: `YYYY-MM-DD-short-title.md`.
3. Fill in the front matter, including `ai_disclosure`.
4. Open a pull request. A member of the editorial group will review it against the checklist in the pull request template.
